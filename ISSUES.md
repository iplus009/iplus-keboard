# iPlus Keyboard — Bug Reports and Feature Requests

Thanks for helping improve iPlus Keyboard.

## Before opening an issue

- Search existing issues for the same problem.
- Use the latest APK or build from the iPlus Keyboard repository when possible.
- Never include passwords, private messages, personal documents, API keys or other sensitive information in an issue.

## Bug report

Please include:

1. Device model and Android version.
2. iPlus Keyboard version or commit.
3. Keyboard language/layout in use (for example English, Avro, Probhat or Jatiyo).
4. Clear steps to reproduce the problem.
5. Expected result and actual result.
6. Whether the problem also happens with built-in themes.

## Feature request

Describe the problem the feature would solve, how you expect it to work, and whether it should work offline.

## Privacy and security

Do not attach private keyboard logs or typed content. If you believe you found a security issue, avoid publishing sensitive details in a public issue.
